# 家庭财富驾驶舱

给「首席 CFO」的家庭财富操作系统配套的实时看板。

## 功能

- 📡 **便宜信号自动更新**：每天定时（北京时间 09:30 / 15:30）通过 GitHub Actions 自动抓取实时行情，计算四个便宜信号
  - 纳指100 回撤
  - 沪深300 股息率
  - 港股科技（恒生科技指数参考）
  - 股债性价比（股息率 − 10年国债收益率）
- 📊 持仓偏离度（手动填市值，自动判断是否需再平衡）
- ✅ 买入决策清单（五关检查）
- 🎯 驾驶舱概览

## 使用

直接访问 GitHub Pages：`https://yangyang1369.github.io/family-wealth-dashboard/`

- 便宜信号自动更新，打开即是最新数据
- 手动填数会覆盖自动值（每个设备独立存储）
- 持仓市值需每周末手动填写

## 文件说明

| 文件 | 作用 |
|------|------|
| `index.html` | 驾驶舱主页面 |
| `fetch_signals.py` | 抓取行情、计算便宜信号的脚本 |
| `.github/workflows/fetch-signals.yml` | 定时任务（每天自动运行脚本） |
| `signals.json` | 脚本输出的数据，页面读取展示 |

## 数据来源

- 腾讯财经行情接口（实时指数价格）
- AKShare（中证指数估值、10年国债收益率、纳指历史数据）

> 仅供个人家庭财富管理参考，不构成投资建议。
